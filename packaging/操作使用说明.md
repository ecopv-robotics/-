# ECOPV 邮件审核工作台｜操作使用说明

## 运行条件

- Windows 10/11，64 位。
- 电脑已安装 Microsoft Edge；本程序不携带 Edge 或 Chromium。
- 包内带有 7-Zip 命令行解压组件，用于读取 RAR 附件；请保留 `tools` 文件夹及其文件。
- 首次配置和业务运行需要能访问公司邮箱、工单系统；包内已带当前中文图片 OCR 所需模型，常规识别无需首次下载模型。
- 不需要安装 Python、开发工具或额外的浏览器自动化环境。

## 首次使用

1. 将 ZIP 解压到有读写权限的本地文件夹，例如桌面下的工作目录。不要直接在压缩包内运行，也不要放入 `Program Files` 等受保护目录。
2. 使用记事本打开 `config.yaml`。将邮箱 IMAP 服务器、端口、邮箱地址和邮箱密码，以及工单系统网址填成公司提供的真实值。配置中的 `example.invalid` 都是不可用占位地址，不能直接运行邮件或工单任务。
3. 保存配置后，双击 `启动工作台.bat`。工作台会在默认浏览器打开本机页面；工单自动化使用已安装的 Microsoft Edge。
4. 首次进入运行控制台，按页面提示导入公司当前使用的代理邮箱表、内部邮箱表和项目名称表。它们没有预置在包中，以免把开发机或其他业务数据交给操作人员。
5. 如页面提示配置缺失或账号错误，先核对 `config.yaml` 与页面中的账号设置。网页只提供邮箱/工单账号等部分设置，IMAP 服务器和端口必须在 `config.yaml` 中配置。

## 日常运行

- 在运行控制台选择日期和阶段，再开始任务。每个阶段的用途、进度和日志会显示在页面中。
- 阶段二会通过 Edge 打开工单系统；运行期间不要关闭 Edge 登录页或工作台服务窗口。
- 当前中文图片 OCR 模型已随包放在 `model_cache` 中，请不要删除该目录。以后更换 OCR 流程或语言时，需要换用包含相应模型的新安装包。
- 关闭浏览器标签页不会自动停止后台任务。先在页面停止/等待任务结束，再关闭启动工作台的命令窗口。
- 这是仅监听本机的工作台，不要把本机页面地址转发或暴露到局域网/公网。

## 数据、备份和升级

- 配置、登录状态、人工复核、导入文件、运行日志和结果都保存在程序文件夹及其运行时生成的子目录中；不会自动上传到其他服务器。
- 需要迁移或重装时，先退出程序并备份 `config.yaml`、`storage`、`data`、`output`、`logs`、`cache` 和 `model_cache`（只备份实际存在的目录）。其中 `config.yaml` 可能包含账号密码，应按公司要求保护，不要通过邮件或聊天发送。
- 升级时先备份上述本地数据，再解压新版本到新文件夹；只把需要保留的数据目录和自己的 `config.yaml` 复制到新文件夹，不要覆盖新版本的 EXE、`_internal`、页面资源或启动脚本。
- 运行文件夹需保持可写。磁盘空间不足、文件被 Excel/WPS 占用或安全软件隔离文件时，任务可能无法保存结果。

## 常见情况

- **双击启动后没有页面：** 保持命令窗口打开，查看其中的报错；确认工作文件夹可写，再检查本机端口是否被安全软件拦截。
- **提示配置无效或无法连接邮箱：** 检查 `config.yaml` 中 IMAP 地址/端口、邮箱密码和邮箱服务器是否允许 IMAP。
- **工单查询无法登录：** 检查工单网址和账号，并确认 Microsoft Edge 可正常打开该网站。
- **图片内容没有识别：** 确认 `model_cache` 文件夹完整且可读；非图片附件的解析不依赖 OCR 模型。
- **升级后看不到以前的复核/结果：** 确认已将旧版的 `storage`、`output` 等需要保留目录复制到新版目录。

## 包含内容

本包仅包含当前项目的运行程序、运行所需依赖、工作台页面资源、安全的空白配置模板、启动脚本、RAR 解压所需的 7-Zip 组件及本说明。它不包含源代码、测试文件、真实账号配置、邮箱/客户数据、运行历史、数据库、结果表格或浏览器安装文件。
